# Lista de Reyes 👑

Lista de regalos por niño, cada uno con su ficha (nombres editables, se pueden añadir más). HTML/CSS/JS puro, sin dependencias.
Los datos se guardan en el navegador (localStorage); usa Exportar/Importar para copias o para pasarlos a otro dispositivo.

Publicación: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
